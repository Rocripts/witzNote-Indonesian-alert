🖥️ Persiapan Instalasi Arch Linux

Komponen yang Dibutuhkan

Menginstall Arch Linux membutuhkan 3 komponen utama:

1. ISO — diperoleh dari "archlinux.org" (https://archlinux.org/)
2. Bootable media — misalnya flashdisk
3. Hard drive

«"p" — Pasti

Bootable media dan hard drive merupakan komponen penting yang diperlukan untuk melakukan instalasi Arch Linux.»

---

📥 Mengunduh Arch Linux ISO

Download file ISO dari archlinux.org.

Untuk mendownload ISO/image, gunakan Torrent/QBitTorrent.

«"p" — Pasti

Menurut isu yang beredar, agar video kita ramai harus ada kucing di dalamnya. 🐈»

---

💾 Membuat Bootable Media dengan Rufus

Untuk burn image, download Rufus melalui Google.

Setelah itu:

1. Buka Rufus.
2. Pastikan flashdisk sudah terpasang.
3. Pilih file ISO/image Arch Linux yang telah diunduh.
4. Disarankan untuk tidak mengubah opsi lainnya kecuali target burn (file ISO/image Arch Linux), jika memang tidak diperlukan.

«"r" — Ragu

Konfigurasi opsi tambahan sebaiknya dipertimbangkan sesuai kebutuhan.»

5. Tekan tombol Start.

⚠️ PERINGATAN

«Rufus akan menghapus seluruh data yang ada di flashdisk.

Gunakan flashdisk baru atau flashdisk yang benar-benar kosong.»

---

🔄 Booting dari Flashdisk

Jika semuanya berjalan dengan aman:

1. Restart PC/laptop.
2. Saat proses loading, tekan salah satu tombol berikut untuk masuk ke Boot Mode/Boot Menu:
   - "F1"
   - "F2"
   - "DEL"
3. Pilih atau ubah boot device ke flashdisk yang berisi hasil burn Arch Linux ISO menggunakan Rufus.
4. Setelah itu, kalian akan masuk ke Arch Linux Live Environment.

«Catatan: Tombol untuk masuk ke Boot Menu dapat berbeda-beda tergantung perangkat.»

⌨️ Mengatur Console Keymap

Secara default, Console Keymap menggunakan layout US.

Sesuaikan dengan tipe console keymap keyboard kalian.

Untuk melihat daftar console keymap yang tersedia, gunakan:

localectl list-keymaps

Setelah menemukan keymap yang sesuai, gunakan:

loadkeys n

Ganti "n" dengan nama console keymap yang ingin digunakan.

Contoh

loadkeys id
